# SEO launch checklist

The website contains the technical SEO foundation. Complete these actions after publishing to GitHub Pages for Google to discover and assess it.

## Before publishing

- [ ] Confirm that `knightmarine.co.uk` is the intended public address. The canonical tags, sitemap and `CNAME` file use this domain.
- [ ] Configure the domain's DNS for GitHub Pages and enable HTTPS in GitHub Pages settings.
- [ ] Check that the public website shows the same phone number, email and address as the Google Business Profile.
- [ ] Replace the sample image used on the antifouling, detailing and refit pages with strong, relevant project photos before launch. Use descriptive filenames and alt text.

## Immediately after publishing

- [ ] Add the site to [Google Search Console](https://search.google.com/search-console) and verify `https://knightmarine.co.uk/`.
- [ ] Submit `https://knightmarine.co.uk/sitemap.xml` in Search Console.
- [ ] Use Search Console's URL Inspection tool to request indexing for the homepage and the priority service pages: Electronics, Power Systems, Antifouling and Detailing.
- [ ] Validate the homepage structured data with [Google's Rich Results Test](https://search.google.com/test/rich-results).
- [ ] Confirm the Google Business Profile has the exact same business name, address, phone number, website address, business categories, service area and opening hours as the live website.

## Ongoing work that builds visibility

- [ ] Publish a short, useful project story whenever notable work is completed (for example: a lithium upgrade, navigation refit or full antifouling job). Include real photos, the type of boat, the work completed and the location when appropriate.
- [ ] Add each new page to the navigation or link to it from a relevant existing service page, then add it to `sitemap.xml`.
- [ ] Keep titles and descriptions specific to each page. Do not add a `meta keywords` tag or repeat location phrases unnaturally.
- [ ] Encourage genuine Google reviews and respond professionally; never add self-authored review markup to the website.
- [ ] Review Search Console performance monthly. Expand pages that gain impressions but have a low click-through rate with clearer titles, descriptions and useful content.

## What is intentionally excluded

- The coming-soon shop page uses `noindex` until there are products and a real purchasing journey. Remove `noindex,follow` from `shop.html` and add it to the sitemap when the shop launches.
- The website does not claim awards, ratings, opening hours, pricing or accreditations that were not supplied. Add only verified business information.
