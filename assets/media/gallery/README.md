# Knight Marine media library

This folder is intentionally empty in the starter site so that the website stays fast and easy to publish. It is structured for a growing image library:

- `electronics/`
- `power/`
- `maintenance/`
- `detailing/`
- `refit/`

Place web-ready images in the relevant folder (preferably WebP or JPEG, under 500 KB each) and reference them from the relevant page. Keep the original 5 GB archive separate as the master library; do not upload all originals to the live website.
